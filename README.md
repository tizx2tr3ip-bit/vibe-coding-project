# Vibe Coding Project

Twenty-five interactive projects in one repository, including twenty explorations in different fields. [Explore the live collection](https://tizx2tr3ip-bit.github.io/vibe-coding-project/).

| Project | Field | What it does | Live project |
| --- | --- | --- | --- |
| Pocket Ledger | Personal finance | Track income and expenses; export a CSV. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/pocket-ledger/) |
| Focus Flow | Productivity | Focus timer with breaks and a session count. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/focus-flow/) |
| Task Lanes | Project management | Move tasks through three stages. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/task-lanes/) |
| Habit Garden | Habit building | Track habits and daily streaks. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/habit-garden/) |
| Note Nest | Writing | Write, search, and export notes. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/note-nest/) |
| Exoplanet Transit Lab | Astronomy | Build a star system and watch a planet dim its star. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/exoplanet-transit/) |
| Chord Forge | Music | Hear how notes combine into color and tension. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/chord-forge/) |
| Fractal Voyager | Mathematics | Zoom into an endlessly detailed Mandelbrot set. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/fractal-voyager/) |
| Launch Window | Physics | Tune a trajectory and predict where a rocket lands. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/launch-window/) |
| DNA Decoder | Biology | Read a DNA sequence as patterns, RNA, and amino acids. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/dna-decoder/) |
| Forest Fire Lab | Ecology | See how density changes the spread of a wildfire. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/forest-fire/) |
| Outbreak Model | Epidemiology | Explore how transmission and vaccination shape an epidemic. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/outbreak-model/) |
| Market Maker | Economics | Move supply and demand to discover a market price. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/market-maker/) |
| Wealth Curve | Finance | Compare saving and compounding over time. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/wealth-curve/) |
| Cipher Studio | Cryptography | Encrypt and decrypt a message with a classic shift cipher. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/cipher-studio/) |
| Word Atlas | Linguistics | Find the most frequent words in a passage. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/word-atlas/) |
| Earth Stretch | Geography | See how a Mercator map exaggerates areas near the poles. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/earth-stretch/) |
| Skyline Lab | Architecture | Generate a city silhouette with tunable density and height. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/skyline-lab/) |
| Traffic Pulse | Urban planning | Watch congestion emerge as more cars share a road. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/traffic-pulse/) |
| Robot Route | Robotics | Place obstacles and find the shortest route through a grid. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/robot-route/) |
| Dilemma Arena | Game theory | Run repeated decisions between competing strategies. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/dilemma-arena/) |
| Contrast Lab | Accessibility | Check how readable a color pairing is. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/contrast-lab/) |
| Poster Machine | Generative art | Make a unique geometric poster from a seed. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/poster-machine/) |
| Chance Engine | Statistics | Estimate π through random sampling. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/chance-engine/) |
| Route Weaver | Logistics | Connect destinations and compare route distances. | [View](https://tizx2tr3ip-bit.github.io/vibe-coding-project/route-weaver/) |

Each project has its own folder and runs in a browser. The simulations are illustrative.
