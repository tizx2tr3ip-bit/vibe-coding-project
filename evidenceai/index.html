OPTIONAL / LOCAL INFERENCE

Bring a model to the desk.

The downloadable version connects to Ollama on this computer. No API key or paid provider is required. Selected source passages are sent to your local model when you request an AI answer.

1. Install Ollama and a local chat model.
2. Run: node server.mjs
3. Open: http://127.0.0.1:4174
4. Connect below and select installed models.

Model downloads and installation are separate. Choose an actual embedding model for semantic search. Citation checks confirm IDs and copied quotes, not whether a claim logically follows from them.

WORKBENCH GUIDE

Trace the answer.

  1. Choose your sources. Check documents in the left panel to control the search scope.
  2. Ask a specific question. Evidence search returns ranked quotations. Local AI mode generates claims from retrieved passages.
  3. Open a citation. The right panel highlights the exact indexed passage and its original line number.
  4. Keep a record. Save useful results to the notebook and export a portable brief or complete workspace.

Sample documents deliberately contain an outdated launch date and a later revision. Compare both sources instead of trusting the first match.

BM25 scores and cosine similarities are ranking signals, not confidence percentages. No matches means the search has no lexical evidence; matches alone do not guarantee an answer exists.
